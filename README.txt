STUDYSPACE - STUDENT TASK AND REVIEW MANAGER

FILES
- index.html: page structure and Dashboard / Review Room navigation
- style.css: responsive layout and styling
- script.js: task management, review techniques, timer, and browser storage

HOW TO RUN
1. Extract this ZIP file.
2. Open the extracted folder in Visual Studio Code.
3. Open index.html with Live Server (or open index.html in a browser).

FEATURES
- Add, complete, remove, and clear completed tasks.
- Dashboard counters for total, completed, and remaining tasks.
- Review Room with Pomodoro, Short Sprint, Deep Focus, 52/17, and Flowtime.
- Timer controls: start, pause, resume, reset, and skip phase.
- Short and long breaks are selected automatically after focus sessions.
- Saves tasks, selected technique, session count, and timer state in localStorage.
- If the browser is refreshed during a running timer, the remaining time is recalculated.

DATA NOTE
Data is stored locally in this browser using localStorage. It is not synced to another
device or browser. Clearing browser site data may erase saved tasks and settings.
